# Student Pass/Fail Prediction 🎓

## 📌 Project Overview
This project uses Machine Learning classification to predict whether a student will Pass or Fail based on relevant student-related factors.

The project is developed using Python in Google Colab.

## 🎯 Problem Statement
To build a classification model that can identify whether a student is likely to pass or fail using the available input features.

## 📊 Dataset
- Dataset: Self-created dataset
- Source: Created manually/programmatically by the project developer.
- The dataset is generated within the notebook using Python code.
- Target Variable: Pass/Fail

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn

## ⚙️ Project Workflow
1. Dataset Creation
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Selection
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Pass/Fail Prediction

## 📈 Model Evaluation
The classification model is evaluated using appropriate classification metrics:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## 🚀 How to Run
1. Open the `.ipynb` notebook.
2. Click Open in Google Colab.
3. Run all cells sequentially.
4. Explore the predictions and evaluation results.
